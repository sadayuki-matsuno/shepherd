Reading the board

盤面の読み方

The board is one column per repository, one card per session, sorted by urgency: needs input → working → idle. Everything below is what the pieces mean. The same legend lives in the app behind the ? button in the HUD header.

盤面はリポジトリごとに1列、セッションごとに1カードで、緊急度順 （応答待ち → 作業中 → 待機）に並びます。以下はそれぞれのパーツの意味です。 同じ凡例は HUD ヘッダーの ? ボタンからアプリ内でも確認できます。

The header

ヘッダー

  • Plan usage dashboard — your Claude plan's 5-hour and weekly windows (plus a model-scoped weekly bar when your plan has one), with time until each resets. A plan chip (e.g. MAX 20X) names the subscription, and a permanent credits column shows extra-usage spend — used / monthly limit / computed remainder (— until you enable extra usage). The fetched-at stamp and the ↻ button on the right refresh everything on demand; when a refresh fails the last good numbers stay up, dimmed, instead of vanishing. When a weekly window passes 90% it's mirrored as an alert chip (threshold configurable). While extra-usage credits are actively burning — plan limits exhausted and the spend counter moving — the credits zone glows amber with a "burning" mark, and an amber "on credits" chip appears in the header row.
  • Range filter — show everything, or only sessions active in the last 24 hours.
  • Count pills — needs input N working N — the board's one-line summary.
  • Controls — minimize (the HUD collapses to a small strip), ＋ new session, ⚙ settings, ? legend.
  • Update badge — once a day Shepherd compares itself against the latest GitHub release; a teal update vX.Y.Z chip appears when a newer one exists. Click it to open the release page, then update with brew upgrade --cask shepherd.
  • プラン使用量ダッシュボード — Claude プランの5時間枠と週間枠（プランにモデル別の週間バーがある場合はそれも）を、それぞれのリセットまでの時間とともに表示します。プランチップ（例: MAX 20X）が契約プランを示し、右のクレジット欄には追加使用量の 使用額 / 月間上限 / 残り が常設表示されます（追加使用量が無効の間は —）。右端の取得時刻と ↻ ボタンで任意のタイミングで全体を再取得でき、取得に失敗しても直前の値が薄くなって残ります（消えません）。週間枠が90%を超えるとアラートチップにも反映されます（閾値は設定可能）。プラン上限を使い切って追加クレジットが実際に消費されている間は、クレジット欄が琥珀色に明滅して「消費中」マークが付き、ヘッダー行にも琥珀の「クレジット消費中」チップが出ます。
  • 表示範囲フィルタ — すべて表示するか、直近24時間にアクティブだったセッションのみ表示するかを切り替えます。
  • 件数ピル — 応答待ち N 作業中 N — 盤面の状態を1行で要約します。
  • コントロール — 最小化（HUD が小さなストリップに折りたたまれます）、＋ 新規セッション、⚙ 設定、? 凡例。
  • 更新バッジ — 1日1回、最新の GitHub Release と自分のバージョンを比較し、新しいものがあると teal の 更新 vX.Y.Z チップが表示されます。クリックでリリースページが開くので、brew upgrade --cask shepherd で更新してください。

The three sections

3つのセクション

Below the header the board splits into three collapsible sections, each behind a ⌄ / › bar. SESSIONS holds the repository columns; folding it moves the status summary — the needs-input / working pills, and the quota alert when one is up — onto the bar itself, so nothing urgent goes dark while the board is tucked away. ARTIFACTS is the shelf and ROUTINES your scheduled cloud agents, both described next. All three fold states persist.

ヘッダーの下で盤面は ⌄ / › バー付きの3つの折りたたみセクションに分かれます。 セッションはリポジトリ列の本体で、畳むと状態サマリ — 応答待ち / 作業中のピルと、出ている場合はクォータ警告 — がバー上に移るので、 畳んでいる間も緊急な情報は消えません。ARTIFACTS は次で説明するシェルフ、 ROUTINES はスケジュール実行されるクラウドエージェントの一覧です。 3つとも開閉状態が保存されます。

The artifact shelf

Artifact シェルフ

The ARTIFACTS section is a persistent, account-wide list of your Claude Artifacts — the pages your sessions publish. Cards only show an artifact while their session lives; the shelf is where they stay findable afterwards.

ARTIFACTS セクションは、あなたのアカウントの Claude Artifact （セッションが公開するページ）の永続的な一覧です。カード上の Artifact バッジはセッションが 生きている間だけですが、シェルフはその後もずっと辿れる置き場になります。

  • Each row — live dot (dimmed grey = deleted on claude.ai), the artifact's favicon, its title, the publishing repo, and the updated date (yyyy/MM/dd). Click to open in the browser; right-click to copy the URL or pin.
  • Search & filter — the search field matches titles and repo names as you type; the popup next to it filters to one repository (or the unattributed group).
  • Pinning — right-click → Pin to top bookmarks an artifact: it wears a pin mark and sorts above everything else. Pins persist.
  • Where the list comes from — two merged sources: the account's own artifact listing (covers other machines and claude.ai, but only returns the ~50 most recently updated) and an incremental scan of this machine's session transcripts (keeps everything ever published here, and adds the favicon + repo attribution). An artifact observed once never drops out of the shelf; older artifacts published on other machines are the one gap.
  • Redeploy pulse — when a session republishes an artifact you may have open in a browser tab, its card's Artifact badge flashes amber: time to reload that tab.
  • 各行 — 生存ドット（灰色の減光 = claude.ai 上で削除済み）、Artifact の favicon、タイトル、公開元リポジトリ、更新日（yyyy/MM/dd）。クリックでブラウザで開き、右クリックで URL コピーやピン留めができます。
  • 検索とフィルター — 検索フィールドは入力しながらタイトルとリポジトリ名に一致し、隣のポップアップで1つのリポジトリ（または帰属不明グループ）に絞り込めます。
  • ピン留め — 右クリック → 上位に固定でブックマークになります: ピンマークが付き、常に最上位に並びます。ピンは保存されます。
  • 一覧の出どころ — 2つの源のマージです: アカウント自身の Artifact 一覧（他のマシンや claude.ai 分もカバーしますが、返るのは直近更新の約50件だけ）と、このマシンのセッション transcript の増分走査（ここで公開したものを全部保持し、favicon とリポジトリ帰属を補います）。一度シェルフに載った Artifact が消えることはありません。唯一の穴は他のマシンで公開された古い Artifact です。
  • リデプロイパルス — ブラウザで開きっぱなしかもしれない Artifact をセッションが再公開すると、そのカードの Artifact バッジが琥珀色に点滅します: タブをリロードする合図です。

Routines

ROUTINES（ルーチン）

The ROUTINES section lists your claude.ai routines — agents that run on a schedule in Anthropic's cloud instead of on this machine. They have no process, no transcript and no terminal here, so they can't appear as cards; this section is the whole of their presence on the board.

ROUTINES セクションは claude.ai の routine — このマシンではなく Anthropic のクラウドでスケジュール実行されるエージェント — の一覧です。 ローカルにはプロセスも transcript も端末も無いのでカードにはなりません。 盤面上での存在はこのセクションが全てです。

  • Each row — a state glyph, the routine's name, its next run in your local time, and a mark for how the last run ended (✓ succeeded, ✗ failed, ⧗ still running). Hover a row for its cron expression and last run time. Click to open the latest run on claude.ai; right-click for the routine's own page or to copy the link.
  • Waiting for approval — when a run stops at a permission prompt the row turns orange and says ? needs approval, exactly as a blocked session's card does. Fold the section and the count moves onto the bar, so a cloud agent waiting on you can't be hidden by tidying up.
  • Disabled routines dim to half, the way an idle card does, and drop the schedule text.
  • Freshness — the list refreshes every couple of minutes whether the section is open or folded; the bar carries the fetch time and a ↻ for right now. A failed fetch keeps the list you had and says so rather than emptying the section.
  • 各行 — 状態グリフ、routine 名、次回実行（ローカルタイム）、直近の実行結果マーク（✓ 成功 / ✗ 失敗 / ⧗ 実行中）。行にホバーすると cron 式と前回実行時刻が出ます。クリックで最新の実行を claude.ai で開き、右クリックで routine 自身のページを開いたり URL をコピーできます。
  • 承認待ち — 実行が権限プロンプトで止まると、行が桃色になり ? 承認待ち と表示されます（応答待ちセッションのカードと同じ扱いです）。セクションを畳むと件数がバー上に移るので、片付けたせいで待たされているクラウドエージェントを見落とすことはありません。
  • 無効な routine は待機カードと同じく50%に減光し、次回実行の表示は消えます。
  • 鮮度 — 一覧は開いていても畳んでいても数分おきに更新され、バーに取得時刻と ↻（即時再取得）が出ます。取得に失敗してもセクションは空にならず、直前の一覧を保ったまま失敗を表示します。

Families: children, forks, and the strip

ファミリー: 子セッション・フォーク・ストリップ

Subagents and teammates nest under their parent card while they work, then disappear when they finish — the board stays as small as the number of workstreams, not the number of processes. Child sessions (a separate claude process your session launched) nest when the parent exported SHEPHERD_PARENT_SESSION_ID; forks are detected automatically and get a branch mark.

サブエージェントと teammate は作業中だけ親カードの下にネストし、終了すると消えます — 盤面はプロセス数ではなくワークストリーム数だけの大きさに保たれます。子セッション （親セッションが起動した別の claude プロセス）は、親が SHEPHERD_PARENT_SESSION_ID を export していればネストします。フォークは自動検出され、ブランチマークが付きます。

The strip along a parent's bottom edge sums it up (2 children · 1 working, plus a blocked child's question when there is one). Click anywhere on the strip to fold or unfold the family; hover while folded to peek without unfolding.

親カードの下端に沿ったストリップがそれを要約します（子 2 件・稼働中 1、加えて子が 応答待ちならその質問も表示）。ストリップのどこをクリックしても家族を畳む/展開でき、畳んだ状態で ホバーすると展開せずに覗き見できます。

The archive lane

アーカイブレーン

Finished background records collapse into one thin lane per repository instead of littering the board. Click to unfold. A finished session can be reopened right where it left off — click its card and Shepherd runs claude attach for it (with a confirmation first).

終了したバックグラウンド記録は、盤面を散らかす代わりにリポジトリごとの1本の細いレーンに畳まれます。 クリックで展開できます。終了したセッションは中断した場所からそのまま再開できます — カードをクリックすると Shepherd が（確認の上で）claude attach を実行します。

Signals worth acting on

対応すべきシグナル

signalmeaningdo
orange banner ? …Agent blocked on a question or permission.Answer it. Everything else is running fine without you.
context gauge redThe window is ≥85% full; quality degrades before the hard limit.Wrap up, or have the agent write a handoff and start fresh.
parked + durationA background worker you forgot to stop, burning memory.Right-click → Stop, unless you're about to attach.
stale?Looks busy, isn't.Attach and check — likely interrupted.
◥ dog-earUncommitted changes.Fine while working; commit or stash before closing.
model chips all one colorNobody chose models for the fleet.See the playbook §2.
シグナル意味対応
オレンジのバナー ? …エージェントが質問または権限プロンプトで停止しています。回答してください。他はあなたなしで問題なく進んでいます。
コンテキストゲージが赤コンテキストウィンドウが85%以上埋まっています。上限に達する前に品質が落ち始めます。作業を締めるか、エージェントに引き継ぎメモを書かせて新しく始めてください。
parked + 経過時間停止し忘れたバックグラウンドワーカーがメモリを消費しています。attach する予定がなければ、右クリック → 停止してください。
stale?作業中に見えても、実際は動いていません。attach して確認してください — おそらく中断されています。
◥ 折り目未コミットの変更があります。作業中は問題ありません。閉じる前にコミットまたは stash してください。
モデルチップが全部同じ色群れ全体でモデルを誰も選んでいません。群れの導き方 §2 を参照。
